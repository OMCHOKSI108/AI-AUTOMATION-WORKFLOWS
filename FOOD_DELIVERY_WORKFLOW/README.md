# 🍽️ Choksi Food Delivery Automation Bot

This project is an **AI-powered Food Delivery Automation System** built with:
- **n8n** (workflow automation)
- **Google Sheets** (inventory database)
- **Telegram Bot API** (customer interaction)
- **WhatsApp Business API** (optional integration)

---

## 🚀 Features
✅ Customers can check available dishes in real-time  
✅ Place food orders via **Telegram / WhatsApp**  
✅ Orders auto-update stock in **Google Sheets**  
✅ AI Agent answers FAQs (store name, delivery policy, etc.)  
✅ Admin can view **online users** & manage orders
