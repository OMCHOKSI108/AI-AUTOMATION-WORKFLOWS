AI Dataset Creator

Transform web content into AI-ready training datasets using advanced extraction and processing

📋 Quick Setup Guide

  1. Make sure n8n is running: docker-compose up -d
  2. Open n8n at http://localhost:5678
  3. Import the workflow JSON from AI_READY_DATASET/ folder
  4. Create Ollama credentials (Base URL: http://localhost:11434, leave API key empty)
  5. Activate the workflow and test it!

🚀 How it works:

  • Enter a URL to scrape content from
  • AI extracts and structures the data
  • Get formatted datasets with titles, summaries, keywords, and topics
  • Data is stored in vector database for future use
